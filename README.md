# Project_3
Multi Encryption Tool
Overview
A desktop application for text encryption and decryption using several popular symmetric cipher algorithms through a simple graphical interface.

Features
User-friendly GUI made with CustomTkinter.

Supports AES, DES, Triple DES, Fernet, Blowfish, RC4, and ChaCha20.

Easily switch between encryption and decryption.

Plaintext and password validation for safe operation.

Copy output with a single click for convenience.

Modular design—extendable with new ciphers.

Technologies Used
Python

CustomTkinter

Pyperclip

Modular Python cipher libraries (OOP approach)

Getting Started
Install required packages:
pip install customtkinter pyperclip

Run main.py to start the graphical interface.

Select an algorithm, enter your text and password, then encrypt or decrypt with a button click.
